Lang3 Website

Experiment with the Lang3 language online

Lang3 is a lightweight, statically typed, object-oriented scripting language focused on flexible object layouts and quality-of-life syntax. Read about the language on GitHub, then explore it here.

Run Lang3 in the browser Browse docs Download options

Interactive runner

The Run page features an Ace editor and file upload so you can send Lang3 snippets to our servers. Jobs are executed via Redis + RQ and stream lexer/parser output back to your browser with friendly status updates.

Living documentation

Markdown files in the repo render automatically under /docs/<page> using Bootstrap templates. Expect syntax notes, language guides, and examples as Lang3 evolves.

Deploy-ready stack

This site ships with Dockerized web, worker, and Redis services plus a GitHub Actions pipeline for automatic builds and SSH deployments, keeping the public playground up to date.

Get involved

Curious about the compiler or core language design? Contribute ideas and code at the main Lang3 repository. Have feedback on the website experience? Open an issue here or reach out via the contact page.
